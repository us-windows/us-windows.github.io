# Windows Help Center — GitHub Pages

This static website contains 71 detailed educational articles supplied for Windows 10 and Windows 11.

## Project files
- `index.html` — searchable homepage and article directory.
- `support.html` — simple support landing page.
- `style.css` — shared responsive styling and header navigation.
- `articles/` — individual article pages with title-based filenames and no serial numbers.
- `article-urls.txt` — all article URLs for the configured GitHub Pages domain.
- `README.md` — publishing instructions.

## Navigation
The header appears on the homepage and every article page. Home, Login, and Support navigation targets are set to `#` as requested. The simple support page is included as `support.html`.

## Publish
1. Extract the ZIP archive.
2. Upload the contents of this folder to the root of your GitHub Pages repository.
3. Keep `index.html`, `support.html`, and `style.css` together in the root, with the complete `articles` folder.
4. Open repository Settings, then Pages.
5. Select Deploy from a branch, choose your publishing branch and the root folder, and save.
6. Wait for deployment to finish.

The article URL list uses `https://uswindowsguide.github.io/`. If this is a project site rather than a user site, include the repository path in each URL.
